# 哈基米塔防 🐱

一款原创的萌宠主题**经典路径塔防 + 宠物收集养成**网页游戏。带领哈基米猫猫和狗勾军团，在粮仓沿线排兵布阵，拦截偷粮的鼠贼军团！

> 本项目为完全原创作品，不包含任何现有游戏的素材、名称或数值。

## 游戏特性

- 🗼 **经典路径塔防**：21 只原创猫狗宠物（N/R/SR/SSR 四档稀有度），5 种定位（射手/炮手/冰系/辅助/对空），纯放置挂机战斗
- 🥚 **孵蛋收集**：猫薄荷抽蛋，SSR 40 抽保底、十连必出 R+，重复宠物自动转碎片
- ⭐ **升星养成**：碎片+猫薄荷升星（最高 5★），每星 +15% 攻击成长
- 🗺️ **8 个手工关卡**：疾风鼠、飞行、护甲三大主题递进，每关末波 Boss 鼠王
- ♾️ **无尽模式**：通关第 8 关解锁，血量速度双重爬坡，挑战最高波数
- 💾 **本地存档**：localStorage 自动存档，支持导出/导入/重置，损坏自动备份恢复
- 📱 **双端自适应**：手机竖屏与电脑宽屏均可游玩
- 🔇 纯单机离线，无音效、无内购、无联网

## 玩法说明

1. **选关出战**：主页选择已解锁关卡，从收藏中挑选最多 6 只宠物编队出战
2. **排兵布阵**：点击地图上的虚线建造格，从底部编队栏选择宠物放置（消耗小鱼干 🐟）
3. **升级/出售**：点击已放置的宠物升级（Lv1→Lv3）或出售（返还 60%）
4. **控制节奏**：1x/2x 加速；波间倒计时可提前召唤下一波（预支该波 50% 清空奖励）
5. **收集养成**：孵蛋屋消耗猫薄荷 🌿 抽新宠物；图鉴中用碎片升星；敌人机制：
   - 🐭 鼠小兵：基础 · 💨 疾风鼠：高速 · 🛡 盾甲鼠：高护甲
   - 🐦‍⬛ 飞贼乌鸦：飞行，**只有"对空"定位的宠物能打到**
   - 👑 鼠王：Boss，定期嚎叫加速全场小怪

## 项目结构

```
src/
├── game/            # 纯 TS 游戏逻辑（零渲染依赖，可独立测试）
│   ├── types.ts     # 全部核心类型
│   ├── path.ts      # 路径/弧长工具
│   ├── data/        # 数值数据表（宠物/敌人/关卡/平衡常量）
│   └── engine/      # GameEngine：固定步长战斗引擎
├── render/          # 渲染层（素材可替换架构）
│   ├── types.ts     # AssetProvider 接口
│   ├── registry.ts  # 素材注册表
│   ├── providers/   # emoji-v1 占位实现（可换矢量/图片素材）
│   └── battleRenderer.ts
├── stores/          # Pinia：档案/货币/收集/抽卡/升星/存档
├── composables/     # useBattleEngine（rAF 循环 + 快照桥接）
├── components/      # 战斗 HUD/画布/菜单、图鉴、通用组件
└── views/           # 主页/战斗/图鉴/孵蛋/设置
tests/               # Vitest：引擎/数据/存档/抽卡/组件/关卡回归
docs/PRD.md          # 产品需求文档（开发与审核的唯一基准）
```

## 架构要点

- **引擎与渲染完全解耦**：`GameEngine` 只产出 `BattleSnapshot` 只读快照，渲染层与 Vue 组件从快照读取；引擎可被 Vitest 直接驱动
- **素材可替换**：所有视觉经 `AssetProvider` 接口 + 注册表访问。当前默认 **矢量萌宠生成器**（`providers/vector.ts`，21 只参数化手绘猫狗 + 5 种装备变体敌人），emoji 实现保留为后备（`providers/emoji.ts`），切换只需改注册表一行
- **动画与特效**：待机呼吸/行进弹跳、攻击后坐、受击闪白、放置弹跳、死亡爆散、金币飘散、Boss 嚎叫冲击波、弹道尾迹、冰霜标记、8 关主题场景装饰（草丛/花丛/灌木/矿石/麻袋/星空）
- **数值全收敛**：宠物/敌人/关卡/经济/保底等全部数值在 `src/game/data/` 数据表与 `balance.ts`，禁止散落硬编码
- **测试闭环**：引擎单测、数据校验、存档容错、抽卡保底数学、挂机通关模拟、关卡门槛回归（L6/L8 可通性锁定）、组件交互测试
